# Changelog

All notable changes to Chrono Study are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Project foundation: Gradle wrapper, version catalog, Android manifest and application shell.
- Material 3 design system with seven theme presets (OLED Black, Charcoal, Pure White, Ocean,
  Amber Focus, Forest, Violet) and accent colours.
- Application theme resources, adaptive launcher icon, splash screen and notification channels.
- Bundled completion tones (chime, bell, marimba, soft, digital, success).
- GitHub Actions: `android-ci.yml` (tests, lint, debug APK artifact) and `release.yml`
  (release APK attached to a GitHub Release).
- Repository documentation: README with logo/banner, architecture, contributing, code of conduct,
  security policy and issue/PR templates.

## [0.1.0] - 2026-10-12

### Added
- Initial public preview of the Chrono Study native Android foundation.
